# 🧩 Post Format Generator

A **Generative AI module** that converts raw **content ideas into high-performing social media posts** optimized for **engagement, readability, and platform growth**.

The system applies **proven creator frameworks used by top marketers, influencers, and content strategists** to transform simple ideas into **ready-to-publish posts**.

---

# 🎯 System Objective

The **Post Format Generator** helps creators convert content ideas into **structured, engaging, and high-impact posts**.

It focuses on three key pillars:

- **Attention** → Strong hooks that stop scrolling  
- **Value** → Useful and actionable insights  
- **Engagement** → Encouraging conversation  

This ensures:

✔ Higher engagement  
✔ Clear messaging  
✔ Strong storytelling  
✔ Better readability  
✔ Faster content creation

# ⚙️ Prompt Design

## ROLE

You are an **expert social media content strategist** who specializes in creating **high-engagement posts for digital platforms**.

---

## OBJECTIVE

Convert a **content idea into a structured social media post** that is optimized for **engagement, clarity, and value delivery**.

---

## INPUT VARIABLES

Topic: `[topic]`  
Platform: `[platform]`  
Audience: `[target audience]`

---

## INSTRUCTIONS

1. Start with a **powerful scroll-stopping hook**  
2. Write the main content using **clear bullet points**  
3. Deliver **practical value or insights**  
4. End with a **call-to-action encouraging engagement**  
5. Adapt tone and style for the **selected platform**
